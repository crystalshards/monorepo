# CrystalDocs.org Documentation Browser UI

## Overview

The CrystalDocs.org documentation browser UI is fully implemented using the Lucky framework. It provides a complete interface for browsing and reading Crystal shard documentation stored in MinIO.

## Architecture

### URL Structure

```
GET /                                  # Homepage with shard list
GET /docs                              # Browse all documentation with search
GET /docs/:package_name                # Latest version docs (redirects)
GET /docs/:package_name/:version       # Specific version documentation viewer
```

### Data Flow

1. **Documentation Storage**: HTML docs generated by `crystal docs` are stored in MinIO
2. **Database**: PostgreSQL stores metadata (Doc, DocVersion models)
3. **Actions**: Lucky controllers handle HTTP requests
4. **Pages**: Lucky HTML views render the UI
5. **Storage Service**: DocsStorageService fetches HTML from MinIO

## Components

### Actions (Controllers)

#### `Home::Index` (`src/actions/home/index.cr`)
- **Route**: `GET /`
- **Purpose**: Homepage with shard overview
- **Features**:
  - Total package and version counts
  - Recently updated packages (last 6)
  - Popular packages (last 6 by views)
- **Queries**:
  ```crystal
  DocQuery.new.preload_doc_versions.last_updated_at.desc_order.limit(6)
  DocQuery.new.preload_doc_versions.total_views.desc_order.limit(6)
  ```

#### `Docs::Index` (`src/actions/docs/index.cr`)
- **Route**: `GET /docs`
- **Purpose**: Browse and search all documentation
- **Features**:
  - Search by package name (ilike query)
  - Pagination (20 per page)
  - Ordered by last_updated_at descending
- **Query params**:
  - `query`: Search term
  - `page`: Page number (default 1)

#### `Docs::Show` (`src/actions/docs/show.cr`)
- **Route**: `GET /docs/:package_name`
- **Purpose**: Show available versions for a package
- **Behavior**: Redirects to latest version if current_version is set
- **Features**:
  - Package metadata display
  - List of all available versions
  - View statistics

#### `Docs::Version` (`src/actions/docs/version.cr`)
- **Route**: `GET /docs/:package_name/:version`
- **Purpose**: Display documentation for specific version
- **Features**:
  - Fetch HTML from MinIO via DocsStorageService
  - Version switcher dropdown
  - Breadcrumbs navigation
  - Links to GitHub source and CrystalShards.org
  - View counter (increments on each view)
- **Query params**:
  - `file`: Documentation file path (default "index.html")
- **Error handling**: Shows VersionNotFoundPage if doc doesn't exist

### Models

#### `Doc` (`src/models/doc.cr`)
- **Columns**:
  - `package_name`: String (unique, indexed)
  - `current_version`: String? (optional)
  - `description`: String? (optional)
  - `repository_url`: String? (optional)
  - `total_views`: Int64 (default 0)
  - `last_updated_at`: Time? (optional)
- **Associations**:
  - `has_many doc_versions : DocVersion`

#### `DocVersion` (`src/models/doc_version.cr`)
- **Columns**:
  - `version`: String (indexed)
  - `published_at`: Time
  - `build_status`: String (default "pending")
  - `storage_path`: String
  - `file_count`: Int32? (optional)
  - `total_size`: Int64? (optional)
  - `metadata`: JSON::Any? (optional)
- **Associations**:
  - `belongs_to doc : Doc`
- **Indexes**:
  - Unique index on `[doc_id, version]`

### Queries

#### `DocQuery` (`src/queries/doc_query.cr`)
- **Auto-generated methods** (from Avram associations):
  - `preload_doc_versions`: Eager load associated doc_versions
- **Auto-generated column methods** (from Avram table schema):
  - `package_name`: Filter by package name
  - `package_name.ilike(pattern)`: Case-insensitive LIKE search
  - `last_updated_at.desc_order`: Order by last_updated_at descending
  - `total_views.desc_order`: Order by total_views descending
  - `select_count`: Count records
  - `limit(n)`: Limit results
  - `offset(n)`: Offset results

#### `DocVersionQuery` (`src/queries/doc_version_query.cr`)
- **Auto-generated methods** (from Avram):
  - Column filters and ordering methods
  - Association preloading

### Operations

#### `SaveDoc` (`src/operations/save_doc.cr`)
- **Permitted columns**: package_name, current_version, description, repository_url, total_views, last_updated_at
- **Validations**:
  - `package_name` is required
  - `package_name` must be unique
  - `total_views` defaults to 0

#### `SaveDocVersion` (`src/operations/save_doc_version.cr`)
- Create and update DocVersion records
- Permitted columns for version metadata

### Services

#### `CrystalDocs::DocsStorageService` (`src/services/docs_storage_service.cr`)
- **Purpose**: Interface with MinIO for documentation storage
- **Methods**:
  - `fetch_doc_file(package_name, version, file_path)`: Download HTML file
  - `list_doc_files(package_name, version)`: List all files in version
  - `docs_exist?(package_name, version)`: Check if docs exist
  - `fetch_index(package_name, version)`: Get index.html
  - `presigned_url(package_name, version, file_path)`: Generate temporary URL
- **Storage key format**: `{package_name}/{version}/{file_path}`
- **MinIO configuration**: Uses `MinIOConfig` from `config/minio.cr`

### Database Migrations

#### `CreateDocs::V00000000000002`

```crystal
create table_for(Doc) do

  add_timestamps
  add package_name : String, unique: true, index: true
  add current_version : String?
  add description : String?
  add repository_url : String?
  add total_views : Int64, default: 0

end
```

#### `CreateDocVersions::V00000000000003`
```crystal
create table_for(DocVersion) do
  primary_key id : Int64
  add_timestamps
  add_belongs_to doc : Doc, on_delete: :cascade, index: true
  add version : String, index: true
  add published_at : Time
  add build_status : String, default: "pending"
  add storage_path : String
  add file_count : Int32?
  add total_size : Int64?
  add metadata : JSON::Any?
end

create_index table_for(DocVersion), [:doc_id, :version], unique: true
```

## User Flows

### Browse Documentation

1. Visit homepage: `GET /`
2. See stats, recent docs, popular docs
3. Click search bar or "View All Documentation"
4. Land on browse page: `GET /docs`
5. Search or scroll through packages
6. Click package card

### View Documentation

1. From browse, click package: `GET /docs/:package_name`
2. Redirects to latest version: `GET /docs/:package_name/:version`
3. Documentation HTML rendered
4. Can switch versions via dropdown
5. Navigate within docs (relative links work)
6. Access GitHub source or CrystalShards page

### Search Packages

1. Enter search term in search bar
2. Submit form: `GET /docs?query=term`
3. See filtered results
4. Results show matching package names
5. Empty state if no matches

## Integration Points

### MinIO
- **Bucket**: Configured via `MinIOConfig.settings.docs_bucket`
- **Key format**: `{package_name}/{version}/{file_path}`
- **Client**: Awscr::S3 library
- **Error handling**: Returns nil if file not found

### CrystalShards.org
- Links from documentation viewer back to package page
- URL format: `https://crystalshards.org/shards/{package_name}`
- Opens in new tab (`target="_blank"`)

### GitHub
- Links to repository from `doc.repository_url`
- Opens in new tab
- "View Source" button in documentation viewer

## Performance Considerations

### Database
- Indexes on `package_name` for fast lookups
- Compound index on `[doc_id, version]` for version queries
- Preloading associations to avoid N+1 queries

### Caching
- Documentation HTML cached in MinIO
- No database caching implemented (could add Redis)

### View Counting
- Incremented on each view
- Error silently ignored if update fails
- Could be optimized with background job

## Security

### HTML Rendering
- Documentation HTML rendered with `raw` helper
- **Assumption**: Crystal docs output is safe
- **Risk**: If docs come from untrusted source, need sanitization

### Input Validation
- Search query passed through Avram query builder
- Protects against SQL injection
- No XSS risk (HTML-escaped by Lucky)
